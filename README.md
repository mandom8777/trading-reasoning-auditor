# Trading Reasoning Auditor

> Continuous, cost-aware audit of crypto trading signals. Every decision
> ships with explainable reasoning and a token-cost / expected-ROI footprint.
> Powered by MiMo multi-agent pipelines.

## Problem

Crypto trading bots are everywhere. Reasoning behind their entries is
opaque. When a trade loses, the operator can't tell whether the strategy
was wrong, the data was wrong, or the model hallucinated.

Existing systems offer either:
- **Closed-source signal services** ("trust us, signal good") with no
  reasoning trail, or
- **Open quant frameworks** (vectorbt, Freqtrade) that surface technical
  indicators but never *narrate* the decision.

Neither tells the operator: "Why this trade, why now, what's the cost of
deciding, and what's the expected return?"

## Solution

Trading Reasoning Auditor watches a market 24/7, audits every signal
generated by upstream strategies, and writes a **cost-aware narrative**
explaining the trade, the reasoning chain, the token cost of producing the
analysis, and the expected ROI. Operators read the narrative before
allowing automation to fire the trade.

## Why MiMo?

This is a long-chain reasoning problem at every step:

- **Strategy explainer** — translate raw indicators into a hypothesis
- **Risk analyzer** — chain micro-events into a probabilistic loss profile
- **ROI projector** — fuse macro context with strategy expectancy
- **Cost auditor** — meta-reason about the model's own token spend

Cheaper instruct-tuned models surface generic narratives; MiMo's reasoning
tokens preserve the hypothesis chain.

## Architecture (one-paragraph)

A 6-agent pipeline runs continuously per monitored market. `signal-detector`
listens to upstream strategy webhooks, `strategy-explainer` (MiMo) writes
a hypothesis, `risk-analyzer` (MiMo) computes loss profile, `roi-projector`
(MiMo) blends macro context, `cost-auditor` (MiMo) narrates the token
footprint and expected ROI, and `report-writer` (MiMo) emits a daily
operator brief. Full diagram in [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Quick start

```bash
git clone https://github.com/<account>/trading-reasoning-auditor
cd trading-reasoning-auditor
pnpm install

export MIMO_API_KEY="..."
export MARKETS="BTCUSDT,ETHUSDT,SOLUSDT"

pnpm dev   # one-shot audit using bundled fixture
pnpm start # continuous mode, polling Binance feeds
```

## Risk disclosure

This tool **does not place trades**. It audits and narrates upstream
strategy signals. Production usage with live capital is the operator's
responsibility.
